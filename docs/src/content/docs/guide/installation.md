## Requirements

- Craft CMS 5.8.0 or later
- PHP 8.2 or later
- A running [Mailpit](https://mailpit.axllent.org/) instance that Craft sends its emails to

## Install

Install the plugin from the [**Plugin Store**](https://plugins.craftcms.com/mailpit) in the Control Panel, or with [Composer](https://packagist.org/packages/somehow-digital/craft-mailpit):

```bash
composer require somehow-digital/craft-mailpit
php craft plugin/install mailpit
```
